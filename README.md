# JEOPARTY

Quiz i Jeopardy-stil med eget brett, lag, poeng og historikk. Kjører på
jeoparty.no.

Appen ligger i [`showdown-grid-nextjs/`](showdown-grid-nextjs/README.md)
(Next.js 16, TypeScript, Supabase). Der står hvordan den henger sammen, hvordan
den kjøres lokalt og hvilke migrasjoner databasen trenger.

`assumptions.md` er beslutningsloggen: hvorfor ting er som de er.
